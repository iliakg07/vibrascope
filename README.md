# ВибраСкоп

Интерактивная учебно-исследовательская платформа для понимания ИК-спектров через движение молекул, жесткость связей и линейную алгебру.

Первая реализованная молекула: **H2CO, формальдегид**.

## Что есть в первой версии

- **Обучение**: ИК-спектр, кликабельные пики, карточки объяснений, анимация молекулы.
- **Моды**: шесть нормальных колебаний H2CO с частотами и описаниями.
- **Жесткость**: графики `V = 1/2 k delta^2`, сравнение жестких и мягких деформаций.
- **Связи и углы**: перевод движения атомов в изменения внутренних координат.
- **Атомы**: вклад атомов в каждую моду через тепловую карту.
- **Практикум**: игровой режим с вариантами ответа и разбором.
- **Эксперт**: режим без подсказок, где пользователь сам описывает пик.
- **База**: данные молекулы и структура для будущего расширения.

## Как запустить локально

Вариант 1: открыть файл `index.html` в браузере.

Вариант 2: запустить локальный сервер из папки проекта:

```bash
python -m http.server 8501
```

После этого открыть:

```text
http://localhost:8501/
```

На Windows также можно запустить файл:

```text
run_server.ps1
```

## Как выложить в интернет

Так как приложение статическое, его можно разместить на GitHub Pages:

1. Создать GitHub-репозиторий.
2. Загрузить папку `vibrascope`.
3. Включить GitHub Pages для ветки `main`.
4. Получить постоянную публичную ссылку.

## Как развивать

Следующие логичные шаги:

- добавить другие молекулы в `data.js`;
- добавить режим сравнения H2CO и D2CO;
- добавить загрузку пользовательской молекулы;
- улучшить 3D-визуализацию через WebGL;
- добавить экспорт отчета по выбранному пику.
